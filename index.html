05 / ABOUT

How I think.

I learn fastest when there is a real problem at the end of the code.

I am a B.Tech IT engineer at MVGR College of Engineering who enjoys moving between product ideas and the systems that make them work.

I started with web development and gradually expanded into backend services, AI applications, realtime systems, mobile development and cloud deployment.

My favourite projects are the ones where the first version is only the beginning — build it, test it, break it, figure out why, then build the better version.

“The interesting part is rarely writing the code. It is deciding what the code should be allowed to do.”
